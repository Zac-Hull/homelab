# Homelab Roadmap

## Purpose

This roadmap outlines the planned evolution of the homelab toward a production-like environment with secure external access, observability, and high availability.

## Short Term
- Validate and expand observability and alerting platform
- Add Uptime Kuma monitoring as an end-user dashboard
- Configure NetBox for documenting network infrastructure
- Configure reverse proxy (Traefik)

## Mid Term
- Complete validation on Draw.io
- Implement HTTPS with Let's Encrypt
- Backup strategy for configs
- Build IAM platform with SSO, LDAP, and secrets management

## Long Term
- Kubernetes cluster across multiple nodes
- High availability services
- Automated backup and restoration testing
