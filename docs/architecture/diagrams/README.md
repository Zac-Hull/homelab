# Architecture Diagrams

This directory contains public-safe architecture diagrams for the homelab.

Diagrams committed here are sanitized before publication.

These do not include details on:

- Private IP address maps
- VLAN details
- Firewall rules
- VPN keys or tunnel details
- Internal-only DNS records
- Sensitive service endpoints
- Credential paths or secret storage details

Private diagrams will remain in the Obsidian vault.
